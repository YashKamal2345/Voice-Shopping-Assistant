# Voice Command Shopping Assistant

A voice-based shopping list manager with smart suggestions, built with React and Web Speech API.

## Features

### 🎤 Voice Input
- Voice command recognition for adding/removing items
- Natural language processing for flexible phrases
- Multi-language support (English, Spanish, French, German)

### 💡 Smart Suggestions
- Personalized recommendations based on purchase history
- Seasonal product suggestions
- Substitute suggestions for unavailable items
- Running low alerts

### 📝 Shopping List Management
- Add/remove/modify items via voice
- Auto-categorization (dairy, produce, snacks, etc.)
- Quantity management
- Check/uncheck items

### 🔍 Voice-Activated Search
- Search items by name, brand, or price range
- Price filtering
- Brand filtering

### 🎨 UI/UX
- Minimalist, clean interface
- Real-time visual feedback
- Mobile responsive design

## Tech Stack

- **Frontend**: React.js, Tailwind CSS
- **Voice Recognition**: Web Speech API
- **NLP**: Compromise.js
- **State Management**: React Hooks
- **Storage**: LocalStorage
- **Animations**: Framer Motion
